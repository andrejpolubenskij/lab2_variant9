## Задание 1. Стоимость парковки по диапазонам

Вводится количество часов от 1 до 24. Первый час стоит 3, часы со 2-го по 5-й — по 2,
каждый час после пятого — по 1.5. Расчёт без циклов, тремя диапазонами.

**Примеры:** 1 час → 3.00; 3 часа → 7.00; 8 часов → 15.50.

## Задание 2. Потерянный талон и выходной день

Если талон потерян — фиксированная сумма 50, остальные правила игнорируются.
Иначе первые 8 часов считаются по 3 за час, время сверх 8 часов не увеличивает стоимость.
В выходной рассчитанная сумма увеличивается на 20 %. Часы проверяются 1..24.

**Примеры:** 5 ч, будний, талон не потерян → 15.00;
10 ч, выходной, талон не потерян → 28.80;
10 ч, будний, талон потерян → 50.00.

## Задание 3. Ставка по виду транспорта

Через `switch`: C — 4/час, M — 2/час, B — 7/час.
При парковке дольше 8 часов расчёт ограничивается стоимостью 8 часов.
Проверяются код транспорта и часы 1..24.

**Примеры:** C, 5 ч → 20.00; M, 10 ч → 16.00; B, 3 ч → 21.00.

## Задание 4. Полный расчёт

Через `switch` задаются ставка и штраф: C — 4/час и 50, M — 2/час и 25, B — 7/час и 80.
При `lostTicket = 1` используется только фиксированный штраф.
Иначе оплачивается максимум 8 часов; в выходной сумма увеличивается на 20 %,
кроме мотоцикла, для которого выходная надбавка не действует.
Выводится правило, по которому получен итог.

**Примеры:** C, 10 ч, выходной, талон не потерян → 38.40;
M, 10 ч, выходной, талон не потерян → 16.00;
B, 5 ч, будний, талон потерян → 80.00.
